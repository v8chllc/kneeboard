### Key context

No application code exists yet. The documentation under `docs/` is the current
source of truth for implementation planning. The MVP targets the CIVA/Delco
Carousel IV-A and the iniBuilds L-1011's modeled Litton LTN-72 units for home

The delivery posture is a lean Vercel soft launch with Neon, Better Auth magic
links, Resend, a fail-closed email allowlist, production-only deployments, and
manual production migrations. Vitest runs in CI; a small Playwright suite is
manual for MVP.

### Decisions considered

- Chose typed domain commands plus a pure reducer and persisted snapshots over
  full event-sourced persistence.
- Chose Neon over a DigitalOcean database for the Vercel-hosted application.
- Chose Resend over SendGrid and Better Auth for database-backed magic links.
- Added optimistic concurrency and OFP-load idempotency at low engineering cost.
- Corrected the assumption that SimBrief Pilot IDs are always seven digits;
  they are variable-length numeric identifiers stored as strings.
- Deferred preview deployments, realtime synchronization, offline/PWA support,
  undo, reset, printing, and Playwright in CI.
